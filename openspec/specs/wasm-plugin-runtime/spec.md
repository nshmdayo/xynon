### Requirement: WASM モジュールのロードとインスタンス化

プラグインランタイムはローカルファイルシステム上の `.wasm` ファイルをロードし、純 Go の WASM ランタイムを用いてインスタンス化 SHALL する。インスタンス化時にはエクスポートされたエントリポイント（少なくとも ABI バージョン宣言関数）の存在を検証する。

#### Scenario: 正しい WASM ファイルをロードする
- **WHEN** ランタイムが ABI 宣言とフックをエクスポートした `.wasm` ファイルをロードする
- **THEN** プラグインインスタンスが作成され、チェーンに登録可能な状態になる

#### Scenario: エントリポイントがない WASM ファイルを拒否する
- **WHEN** ランタイムが必要なエクスポート関数を持たない `.wasm` ファイルをロードする
- **THEN** ランタイムはエラーを返し、そのプラグインをチェーンに登録しない

### Requirement: ホスト ABI の提供

ランタイムはプラグインに対して、リクエスト/レスポンスのヘッダ参照・変更、ステータスコードの設定、短絡応答の指示、ログ出力など最小限のホスト関数を `env` もしくは同等のインポート名前空間で提供 SHALL する。リソースはハンドル ID を介してのみ参照される。

#### Scenario: プラグインからヘッダを取得する
- **WHEN** プラグインが有効なハンドル ID を引数に `get_header` を呼び出す
- **THEN** ランタイムは対応するリクエスト/レスポンスのヘッダ値をゲストのメモリに書き込む

#### Scenario: プラグインからヘッダを変更する
- **WHEN** プラグインが `set_header` を呼び出してヘッダ名と値を指定する
- **THEN** ランタイムは対応するリクエスト/レスポンスのヘッダを書き換える

#### Scenario: プラグインが無効なハンドルを使う
- **WHEN** プラグインが存在しない、または有効期限切れのハンドル ID を渡す
- **THEN** ホスト関数はエラーコードを返し、ホスト内部のデータは変更されない

### Requirement: ABI バージョンの検証

ランタイムはロード時にプラグインの申告する ABI バージョンを取得し、ホストがサポートするバージョン集合に含まれない場合はロードを拒否 SHALL する。

#### Scenario: 非対応の ABI バージョンを拒否する
- **WHEN** プラグインがホスト非対応の ABI バージョンを申告する
- **THEN** ランタイムはロードエラーを返し、チェーンに追加しない

### Requirement: プラグイン実行のサンドボックス境界

プラグイン実行にはコンテキスト経由でキャンセル可能な実行時間制限、およびゲストメモリの上限が適用 SHALL される。制限超過時はホスト側で実行を打ち切り、エラーとして扱う。

#### Scenario: 実行時間が制限を超える
- **WHEN** プラグインのフックが設定された実行時間制限を超過する
- **THEN** ランタイムは実行をキャンセルし、エラーを返す
- **AND** ホストは当該プラグインをそのリクエスト処理から除外する

#### Scenario: メモリ上限を超える
- **WHEN** プラグインのメモリ使用量が設定された上限を超えようとする
- **THEN** ランタイムは追加確保を拒否し、実行はエラーで終了する
