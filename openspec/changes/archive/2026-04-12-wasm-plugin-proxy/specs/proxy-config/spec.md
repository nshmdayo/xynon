## ADDED Requirements

### Requirement: 設定ファイルのロード

プロキシは起動時に YAML 形式の設定ファイルを読み込み、リスンアドレス・プラグインディレクトリ・プラグインチェーン順序・プラグイン実行制限（タイムアウト、メモリ上限）を取得 SHALL する。

#### Scenario: 有効な設定ファイルを読み込む
- **WHEN** プロキシを正しい YAML 設定ファイルで起動する
- **THEN** プロキシは設定に従ってリスナを起動し、プラグインディレクトリの監視を開始する

#### Scenario: 設定ファイルが存在しない
- **WHEN** 指定されたパスに設定ファイルが存在しない
- **THEN** プロキシは起動を中止し、原因を示すエラーメッセージを出力する

#### Scenario: 設定の必須項目が欠落している
- **WHEN** 設定にリスンアドレスやプラグインディレクトリなどの必須項目が欠けている
- **THEN** プロキシは起動を中止し、欠落フィールド名を含むエラーを出力する

### Requirement: プラグインチェーン順序の宣言

設定ファイルは、ロード対象のプラグインとその実行順序を明示的に宣言 SHALL する。宣言されていない `.wasm` ファイルはチェーンに含めない。

#### Scenario: 設定に列挙されたプラグインのみ使用される
- **WHEN** 設定ファイルに A と B の 2 つのプラグインがこの順で列挙されているが、ディレクトリには C も存在する
- **THEN** チェーンは A → B の順で構成され、C はチェーンに含まれない

### Requirement: 設定ファイル自体のホットリロード非対応

設定ファイルの内容変更は起動時にのみ反映 SHALL され、ランタイム中の再読み込みは行わない。変更を反映するにはプロキシの再起動が必要であることをエラーメッセージやドキュメントで明示する。

#### Scenario: 実行中に設定ファイルを変更する
- **WHEN** プロキシ実行中に設定ファイルの内容が変更される
- **THEN** プロキシは変更を自動的に反映しない
- **AND** 変更を有効にするにはプロキシを再起動する必要がある
